# CapybaraClicker

Курсовая работа по дисциплине КПиЯП, 3 курс.
Кликер-игра про капибару на Unity: кликай, прокачивайся, открывай скины и веди свой профиль.

## О проекте

**CapybaraClicker** — десктопная игра в жанре clicker/idle, где игрок
зарабатывает очки кликами по капибаре, тратит их в магазине на апгрейды
и косметические скины, а прогресс сохраняется в локальной базе данных
для каждого профиля.

**Цель работы:** изучить разработку игрового приложения на Unity,
освоить работу с базой данных в C#, реализовать систему сохранений
и профилей пользователей.

## Стек технологий

- **Движок:** Unity 2022.3 LTS
- **Язык:** C# (.NET Standard 2.1)
- **База данных:** SQLite 
- **UI:** Unity UI (uGUI) / TextMeshPro
- **Графика:** [Aseprite / Photoshop] — спрайты
- **Инструменты:** Git, Visual Studio / Rider
